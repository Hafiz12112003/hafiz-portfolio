    (03) Selected work

    Built, tested, shipped.

    1. A call-quality inspector for AI voice agents. It runs rule-based checks over call transcripts, scores each call and lets a reviewer step through findings on a conversation timeline. A “Try it” workbench analyses any pasted transcript, and a Rules page documents every check.

      250+ frontend and 250+ backend tests, and an accuracy page that says plainly the checks aren’t yet validated on real calls.

      React 19 · Vite · Tailwind v4 · Recharts · Flask 3 · SQLite · pytest
      Live demo ↗Code ↗

    2. A pipeline that pulls GitHub issues and Google Play reviews into one schema, clusters them into themes and links each theme back to its evidence in a React viewer.

      Evaluated honestly: F1 of 0.63 against 0.38 for a word-count baseline.

      Python · TypeScript · React · clustering
      Live demo ↗Code ↗

    3. A prototype account-intelligence pipeline. It reads usage, CRM and call signals, decides whether an account is at risk, explains why with citations to the exact records and waits for a person to approve the next action. Any finding with a bad citation is rejected.

      On 16 synthetic accounts the LLM scored F1 0.83 (strict) against 0.67 for rules alone. The README treats it as a prototype, not a benchmark.

      FastAPI · Postgres + pgvector · Redis · Groq · React + TypeScript
      Live demo ↗Code ↗

    4. An AI support platform for an e-commerce store. A retrieval pipeline grounds a Llama 3.3 70B model (via Groq) in store data, behind a Flask backend with 15+ REST APIs, JWT and bcrypt auth.

      15+ REST APIs with JWT and bcrypt auth, and answers grounded in the store’s own data instead of guesses.

      Flask · MongoDB Atlas · React + Vite · Groq · JWT / bcrypt
      Live demo · soonCode ↗

    5. A football scouting platform that models players, clubs and relationships as a graph, with a force-directed d3 visualisation to explore connections.

      Delivered as a client assignment for Wexa AI and deployed on Render.

      Flask · Neo4j / CognoDB · React 18 + Vite · Tailwind · d3-force
      Live demo ↗Code ↗

    6. Final-year project. I benchmarked EfficientNet, ResNet and DenseNet for diabetic retinopathy detection, then wrapped the best model in a Flask and React app with risk dashboards.

      90%+ accuracy on the benchmark.

      TensorFlow · EfficientNet · ResNet · DenseNet · Flask · React
      Live demo · soonCode ↗
